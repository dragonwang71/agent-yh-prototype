# ADR 0001: Source-grounded agent

- Status: Accepted
- Date: 2026-07-15

## Context

買い物、天気、周辺施設は時間で変化します。モデルだけで候補を生成すると、存在しない商品、古い価格、誤った場所を表示する可能性があります。

## Decision

モデルは intent と次の検索条件を決めるために使い、利用者へ見せる商品・価格・評価・場所・降水量は Yahoo! JAPAN API の返却値だけから構成します。取得できない項目は補完しません。

## Consequences

- 回答の根拠と実行過程を説明しやすい。
- 外部 API 障害時は候補を返せないが、誤った候補を表示するリスクを下げられる。
- API 契約、timeout、fallback、観測可能性を継続して保守する必要がある。
