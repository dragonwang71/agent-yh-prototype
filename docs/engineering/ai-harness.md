# AI harness

## 目的

モデル名、prompt、抽出ルールを変更したときに、見た目の印象だけで品質を判断しないための評価基盤です。

## 現在の評価面

1. 代表的な日本語・英語・中国語入力の routing
2. 商品、上限予算、地名の抽出
3. 雨天時に屋外候補を選ばない guardrail
4. モデルが許可外の施設タイプを返した場合の拒否
5. NDJSON イベントから UI へ渡す `AgentRun` 契約

## 実行

```bash
npm run harness
```

外部 API の商品名や検索順位は時間で変化するため、オフライン評価では固定しません。実データ接続はブラウザ smoke test で確認し、harness は routing と安全条件に集中します。

## 変更ルール

- 不具合修正では、再現ケースを先に `harness/cases/` へ追加する。
- model / prompt 変更では、既存ケースを通した後に新しい期待行動を追加する。
- fixture に秘密情報、実ユーザーの会話、個人情報を保存しない。
- 評価に合格しても、外部 API の仕様変更と UI の視覚確認は別に行う。
