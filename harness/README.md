# Agent harness

このディレクトリは、モデルや prompt を変更しても Agent yh の基本動作を維持するための実行可能な評価セットです。

`npm run harness` は、次をオフラインで確認します。

- 日本語・英語・中国語の代表的な依頼が正しいシナリオへ進むこと
- 商品、予算、場所の決定的な抽出が維持されること
- 雨天時に屋外検索を選ばないこと
- ストリーミング応答が UI 契約を満たすこと

ケースを追加するときは `cases/agent-routing.json` に、実際に守りたい利用者行動を一件ずつ追加します。外部 API の順位や商品名のように時間で変わる値は固定しません。
